# MyLifeStyle — Telegram-бот для учёта финансов

Персональный финансовый менеджер прямо в Telegram: быстрый учёт доходов и расходов,
категории, бюджеты, отчёты с графиками и полноценное **Telegram Mini App** (веб-приложение
внутри бота).

## Возможности

### 🤖 Бот (aiogram 3)
- ⚡ **Быстрое добавление** прямо из чата: напиши «Кофе 250», «Продукты 3000 в Пятерочке»,
  «Получил зп 80000» — бот распознает сумму, тип (доход/расход) и категорию.
- 🗂️ **Категории**: стандартные (еда, транспорт, жильё...) + пользовательские.
  Автоматическая категоризация по ключевым словам.
- 🎯 **Бюджетирование**: месячные лимиты по категориям, прогресс-бары, предупреждения
  при приближении к лимиту.
- 📊 **Отчёты**: итоги за 7 дней / месяц / прошлый месяц, разбивка по категориям.
- 📱 **Кнопка открытия Mini App** в главном меню.

### 📱 Mini App (веб-приложение)
- Адаптивный интерфейс в стиле Telegram (поддерживает тёмную/светлую тему).
- Добавление операций с выбором категории, даты, комментария.
- 🎤 **Голосовой ввод** через Web Speech API.
- Круговая диаграмма структуры расходов, график динамики по дням.
- Сравнение с предыдущим периодом, тренды.
- Управление бюджетами и категориями.
- Подписывает все запросы Telegram `initData` (проверка подписи HMAC на бэкенде).

## Технологии

- **Python 3.10+**
- [aiogram 3](https://docs.aiogram.dev/) — бот
- [FastAPI](https://fastapi.tiangolo.com/) — REST API + раздача Mini App
- **SQLite** (aiosqlite) — хранилище (нулевая конфигурация)
- Vanilla JS + HTML + Canvas (без фреймворков, без внешних CDN кроме Telegram SDK)

## Установка и запуск (локально)

1. **Клонируйте и установите зависимости:**
   ```bash
   git clone <your repo> mylifestyle
   cd mylifestyle
   python -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Создайте бота в Telegram:**
   - Напишите [@BotFather](https://t.me/BotFather), создайте бота и получите токен.
   - Скопируйте `.env.example` → `.env` и вставьте токен:
     ```
     BOT_TOKEN=123456:AA...
     ```

3. **Запуск для разработки (long-polling + локальный сервер):**

   Нужно запустить два процесса:
   ```bash
   # Терминал 1 — бот (polling)
   python bot_polling.py

   # Терминал 2 — веб-сервер для Mini App (http://localhost:8000)
   python server.py
   ```

4. **Доступ к Mini App в Telegram:**

   Чтобы Telegram открыл Mini App, ему нужен HTTPS-URL. Для локальной разработки можно:
   - Использовать `ngrok` / `cloudflared` для туннелирования `localhost:8000`:
     ```bash
     ngrok http 8000
     ```
   - Полученный https-URL пропишите в `.env` как `WEBAPP_URL` (без слеша на конце):
     ```
     WEBAPP_URL=https://xxxx-xx-xx.ngrok-free.app
     ```
   - Перезапустите бота. В @BotFather через `/newapp` / `Menu button` подключите
     Mini App с URL `${WEBAPP_URL}/app`.
   - В режиме отладки `DEBUG=True` API принимает запросы без подписи (удобно тестировать
     в браузере). В продакшене обязательно выключите.

## Продакшен

- Настройте reverse proxy (nginx/Caddy) на HTTPS (Telegram **требует** HTTPS для Mini App).
- Укажите публичный `WEBAPP_URL` в `.env`, выставьте `DEBUG=False`.
- Запускайте FastAPI через uvicorn/gunicorn (под systemd или в контейнере).
- Бота можно запустить либо через polling (как есть), либо подключить через webhook
  FastAPI (для этого достаточно добавить роут `/webhook` к `bot.dispatcher`), если
  нужно обойтись одним процессом.
